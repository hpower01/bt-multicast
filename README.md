# Bluetooth A2DP Multicast – בנייה ב-GitHub

שידור שמע בלוטוס לכמה אוזניות או רמקולים במקביל, לאנדרואיד 13 מבוסס AOSP.
הבנייה רצה על השרתים של GitHub, ולא צריך להתקין שום דבר על המחשב.

## לפני שמתחילים
- Bootloader פתוח ו-**Magisk** (או KernelSU) מותקן על הטלפון.
- חשבון GitHub (חינם).

## שלב 1: ליצור מאגר (repository)
1. נכנסים ל-https://github.com/new
2. שם: `bt-multicast`. מסמנים **Public**. (במאגר ציבורי השרת חזק פי 2, ובפרטי הבנייה לא תסתיים בזמן.)
3. לוחצים **Create repository**.

## שלב 2: להעלות את הקבצים
1. בעמוד של המאגר: **Add file → Upload files**, גוררים את `a2dp_multicast.patch` ולוחצים **Commit changes**.
2. **Add file → Create new file**. בשם הקובץ כותבים בדיוק:
   `.github/workflows/build.yml`
   מדביקים את כל התוכן של הקובץ `build.yml` ולוחצים **Commit changes**.

## שלב 3: גרסת ה-AOSP (כבר מוגדרת ל-M305)
הספרייה חייבת להתאים לגרסה שעל הטלפון, אחרת הבלוטוס יקרוס.
לפי ה-build.prop של המכשיר (`TP1A.220624.014`, תיקון אבטחה `2023-04-05`, MTK `alps-mp-t0`)
הגרסה המתאימה היא `android-security-13.0.0_r6`, וזו ברירת המחדל בקובץ.
אין צורך לשנות כלום.

## שלב 4: להריץ את הבנייה
1. לשונית **Actions**. אם מופיעה בקשה, לוחצים **I understand… enable**.
2. בצד שמאל בוחרים **Build Bluetooth A2DP multicast** ואז **Run workflow**.
3. משאירים את ברירות המחדל (`android-security-13.0.0_r6` ו-`lib`).
4. **Run workflow**. הבנייה לוקחת 3 עד 6 שעות.
5. בסוף נכנסים לריצה, ובתחתית העמוד תחת **Artifacts** מורידים את הקובץ.
   בתוכו יש `a2dp_multicast_magisk.zip`.

## שלב 5: התקנה
1. מעבירים את `a2dp_multicast_magisk.zip` לטלפון.
2. Magisk ← Modules ← **Install from storage** ← בוחרים את הקובץ ← Reboot.
3. אפשרויות מפתחים: **השבת עוצמת קול מוחלטת** (Disable absolute volume) = מופעל.
4. מחברים שתי אוזניות ומנגנים.
   אם אחת מהן תומכת ב-AAC או LDAC, מכבים לה "HD Audio" בהגדרות המכשיר כדי ששתיהן יעבדו ב-SBC.

## אם משהו לא עובד
- הבלוטוס קורס או לא נדלק: מוחקים את המודול ב-Magisk ומפעילים מחדש. ככה חוזרים למצב המקורי.
  בדרך כלל זה אומר שהגרסה בשלב 3 לא מתאימה.
- הבנייה ב-GitHub נכשלה: פותחים את הריצה, לוחצים על השלב האדום ומעתיקים את 50 השורות האחרונות.
